# GERM PCB
## Intro
- This repository holds all the PCB information to allow for seamless syncing between team members who want to work on the design for GERM
- The design files for this project are built from **KiCAD**, and is what we will be using throughout the remainder of the project

## Design
- Design choices for this PCB are per the documentation in the [[https://drive.google.com/drive/u/0/folders/1dtvyD7S52Tu-Nz1_2z5B_uvttlOJOdOd|Drive]]

## Installation
- For installation open kicad and go to the top left corner and open repo, copy the link from github and put in your github information
- That's it!
